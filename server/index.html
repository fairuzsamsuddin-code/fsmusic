Your own free YouTube music server

Run Invidious on Oracle Cloud's free tier. FS Music then plays YouTube songs ad-free, and they keep playing when your iPhone is locked. You can do every step on your iPhone, and it takes about 45 minutes.

Before you start
  • You'll need: an email address, a phone number, and a credit or debit card. Oracle uses the card only to verify you; staying within the free limits costs nothing.
  • Apps: Safari, and Termius (free) to type commands on the server.
  • Tip: Oracle's website is easier on iPhone in desktop mode. Tap aA in Safari's address bar, then Request Desktop Website.
Honest heads-up: YouTube blocks cloud servers more often than home internet. This setup may work for months, or YouTube may block it. Nothing breaks either way: FS Music automatically goes back to the embedded YouTube player and previews.

1Create an SSH key in Termius

This is the "key" that lets Termius log in to your server securely.

  1. Install Termius from the App Store and open it. You can skip creating a Termius account.
  2. Go to Keychain → + → Generate Key.
  3. Name it fsmusic, keep the default type, and tap Save.
  4. Tap the new key and choose Copy public key (sometimes shown as Share → Copy). It starts with ssh-ed25519 or ssh-rsa. Keep it on your clipboard for step 3.

2Create your Oracle Cloud account

  1. Open signup.cloud.oracle.com and choose the free account.
  2. Home Region: pick the one closest to you. It can't be changed later. If you're offered a choice, less popular regions often have more free servers available.
  3. Verify your email, phone and card. Then wait for the "Your account is ready" email. That usually takes minutes, but can take a few hours.
  4. Sign in at cloud.oracle.com.

3Create the free server

  1. Tap ☰ (top left) → Compute → Instances → Create instance.
  2. Name: fsmusic
  3. Image: Change image → Ubuntu → Canonical Ubuntu 24.04 → Select.
  4. Shape: Change shape → Ampere → VM.Standard.A1.Flex. Set OCPUs to 1 and Memory to 4 GB, then Select. It should say Always Free-eligible.
  5. Tap Next to reach the Networking step (Oracle's form is a step-by-step wizard):
    • Primary network: Create new virtual cloud network, with the suggested name.
    • Subnet: Create new public subnet.
    • Primary VNIC IP addresses: turn on Automatically assign public IPv4 address.
    • Add SSH keys, further down the same step: choose Paste public keys and paste the key from step 1.
  6. Tap Next through Storage (leave the defaults), then Create on the Review step.
  7. Wait until the status turns Running (1–2 minutes). Then copy the Public IP address from the instance page.
Why 1 CPU and 4 GB? Oracle may take back free servers that look idle: all of CPU, network and memory use under 20% for a week. On 4 GB, the music server uses enough memory to stay above that line, and it's plenty fast.
Public IPv4 switch missing or greyed out? New accounts sometimes need the network made first. In a new tab: ☰ → Networking → Virtual cloud networks → Actions / Start VCN Wizard → Create VCN with Internet Connectivity → name it fsmusic-vcn → Next → Create. Back in the instance wizard, refresh, then pick Select existing virtual cloud network → fsmusic-vcn and its public subnet. The switch is then available.

Already created the server without a public IP? Open the instance → Networking / Attached VNICs → your VNIC → IP administration → ⋯ → Edit → Ephemeral public IP → Update.
"Out of capacity" error? That's common: Oracle's free ARM servers are popular. Your form stays filled in, so try these in order:
  1. Another availability domain. Scroll up to Placement → Availability domain. If you see AD-2 or AD-3, pick one and tap Create again. Many regions only have AD-1, so skip this if that's all you see.
  2. Try again later. Capacity frees up during the day. Early morning or late night often works. Re-tapping Create every so often is fine.
  3. Use the always-available free AMD server instead. Go back to Image and shape → Change shape → Specialty and previous generation → VM.Standard.E2.1.Micro (also Always Free-eligible). Keep the Ubuntu 24.04 image. It's smaller (1 GB memory), but the installer adds swap space automatically, and it's enough for one person's music. The first start just takes a few extra minutes.

4Connect to the server

  1. In Termius: Hosts → + → New Host.
  2. Address: the Public IP from step 3. Username: ubuntu. Key: select fsmusic. Tap Save.
  3. Tap the host to connect and accept the fingerprint prompt. You're in when you see a line ending in $.

5Install the music server

Copy this one line, paste it into Termius (long-press → Paste), and press return:

curl -fsSL https://fairuzsamsuddin-code.github.io/fsmusic/server/install.sh | bash

It installs Docker and sets up Invidious, Invidious Companion and its database with fresh secret keys. It also adds a free secure web address and a weekly auto-update. It takes about 5–10 minutes. Keep Termius open until it finishes. Read the script.

When it's done, you'll see:

Your server is running!
Server address: https://some-random-words.trycloudflare.com
✔ YouTube search works · ✔ Song playback works

Long-press the address in Termius and copy it.

6Connect FS Music

  1. Open FS Music → ☰ Settings.
  2. Scroll to YouTube Servers (Advanced) → Add Custom Server.
  3. Paste the address, choose Invidious, and tap Add.
  4. Play a song. Under the artist it should say YouTube · your server. Lock your phone, and the music keeps going.
That's it. Search now covers all of YouTube, with no ads, and Autoplay uses YouTube's own "related songs".
Everyday use

Handy commands (type in Termius)

fsmusic-urlShows your server's current address
fsmusic-updateUpdates the server. Run it when songs stop playing; it fixes most YouTube changes
fsmusic-logsShows what the server is doing (Ctrl+C to stop)

The server also updates itself every Sunday night.

If the server restarts, its address changes

The free tunnel gets a new address whenever the server reboots, which is rare. When songs suddenly stop working, connect with Termius and run:

fsmusic-url

Then add the new address in FS Music the same way. It automatically replaces the old one.

Troubleshooting
"✘ Song playback didn't work" or songs fail in the app

Wait 5 minutes: Companion sometimes needs a little time to set up its first YouTube session. Then run fsmusic-update and try again. If it keeps failing, YouTube is probably blocking Oracle's IP address, a known risk with cloud servers. FS Music keeps working with the embedded player and previews in the meantime. Blocks are sometimes lifted after a while.

Termius says "Permission denied (publickey)"

Check that the username is ubuntu and the fsmusic key is selected. If the key wasn't added during step 3, the easiest fix is to delete the instance and create it again with the key pasted in.

The installer stopped with an error

Just run the same install line again. It's safe to repeat, and it picks up where it left off without changing your keys.

Will Oracle charge me?

Not while you stay on the Always Free resources: one A1.Flex server with 1 CPU and 4 GB, and the default disk. Free accounts can't run up charges. Oracle may still reclaim an idle free server. If that happens, create a new one by repeating steps 3–6.

How do I remove everything?

In Oracle Cloud: Compute → Instances → your instance → More actions → Terminate, and tick "permanently delete the boot volume". In FS Music, remove the server from the list in Settings.

Invidious and Invidious Companion are open-source projects by the Invidious team. Using them sits outside YouTube's terms of service, so keep your server for personal use.
