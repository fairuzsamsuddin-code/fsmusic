YouTube API Key (optional)
Lets you search all of YouTube and finds more full songs. Free, about 100 searches a day.
How to get a free key (5 minutes)
  1. Open YouTube Data API v3 in Google Cloud (sign in with any Google account, create a project if asked) and tap Enable.
  2. Go to Credentials → Create credentials → API key, and copy it.
  3. Recommended: edit the key → Application restrictions: Websites → add , and restrict it to the YouTube Data API.
  4. Paste it above and tap Save. No billing or card is needed.
